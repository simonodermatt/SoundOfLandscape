1. Grundsatz der Datenvermeidung

Der Schutz Ihrer Privatsphäre ist mir wichtig. Diese Web-Anwendung („Panorama Synthesizer“) wurde so konzipiert, dass sie grundsätzlich ohne die Erfassung personenbezogener Daten genutzt werden kann. Es werden weder E-Mail-Adressen, echte Namen, noch Nutzerprofile abgefragt oder für Werbezwecke getrackt.

2. Datenbank-Architektur: Supabase (PostgreSQL Cloud-Datenbank)

Moderne Cloud-Datenbank mit Supabase:
Zur sicheren und performanten Speicherung von Community-Presets, Panoramen und mehrsprachigen UI-Texten nutzt diese Anwendung eine Supabase PostgreSQL-Datenbank. Alle Abfragen erfolgen transportverschlüsselt über HTTPS REST-Schnittstellen mit Row Level Security (RLS).

3. Welche Daten wir speichern (Community Presets & Vinyl Mode)

Wenn Sie sich entscheiden, eine Klangeinstellung (Preset) mit der Community zu teilen, speichern wir ausschließlich folgende Daten in der Supabase-Datenbank:

  • Ein Pseudonym (Spitzname), das Sie frei wählen können.
  • Eine zufällig generierte, anonyme User-ID (im lokalen Speicher Ihres Browsers), um Ihre eigenen Einträge zuzuordnen (damit Sie diese später selbst wieder löschen können).
  • Die technischen Parameter des Synthesizers (z. B. gewählte Tonleiter, Wellenform, Regler-Werte für Gipfel, Täler, Echo, Grid-Lines etc.).
  • Vinyl- und KI-Daten: Falls Sie den Vinyl-Modus oder die KI-Begleitung nutzen, werden die zugehörigen Höhendaten-Arrays (vinyl_array) und Notensequenzen (is_ai, ai_sound) gespeichert.
  • Einen Zeitstempel der Speicherung.

Diese Daten erlauben keinen Rückschluss auf Ihre reale Person. Bitte verwenden Sie als Pseudonym keine echten Vor- und Nachnamen, wenn Sie anonym bleiben möchten.

4. Lokaler Speicher (Local Storage)

Um Ihren gewählten Spitznamen, Ihre anonyme User-ID und Sprachpräferenzen für zukünftige Besuche auf Ihrem Endgerät zwischenzuspeichern, nutzt diese Website die „Local Storage“-Funktion Ihres Browsers. Wir setzen keine Tracking-Cookies oder Analyse-Tools ein, um Ihr Surfverhalten zu überwachen.

5. Externe Dienste (Hosting, Datenbank & Karten)

Diese Website greift auf externe Dienste zurück, um technisch funktionieren zu können:

  • GitHub Pages: Die Website wird über GitHub gehostet. Beim Aufruf der Seite überträgt Ihr Browser aus technischen Gründen standardmäßig Ihre IP-Adresse an die Server von GitHub.
  • Supabase: Bereitstellung der Cloud-Datenbank (PostgreSQL / REST API). Beim Speichern oder Laden von Presets kommuniziert Ihr Browser direkt und verschlüsselt mit den Supabase-Servern.
  • OpenStreetMap: Kartenansichten werden über freie Kacheln von OpenStreetMap eingebunden.

6. Ihre Rechte & Löschung

Sie können Ihre eigenen, mit Ihrem Pseudonym gespeicherten Presets jederzeit über das Interface der Website selbst wieder löschen. Wenn Sie Ihren lokalen Speicher (Local Storage) in den Browser-Einstellungen leeren, wird auch Ihre anonyme User-ID gelöscht. Danach können zuvor erstellte Presets nicht mehr durch Sie selbst aus der Datenbank entfernt werden.

Datenschutzerklärung

1. Grundsatz der Datenvermeidung

Der Schutz Ihrer Privatsphäre ist mir wichtig. Diese Web-Anwendung („Panorama Synthesizer“) wurde so konzipiert, dass sie grundsätzlich ohne die Erfassung personenbezogener Daten genutzt werden kann. Es werden weder E-Mail-Adressen, echte Namen, noch Nutzerprofile abgefragt oder für Werbezwecke getrackt.

2. Welche Daten wir speichern (Community Presets)

Wenn Sie sich entscheiden, eine Klangeinstellung (Preset) mit der Community zu teilen, speichern wir ausschließlich folgende Daten in unserer Datenbank:

  • Ein Pseudonym (Spitzname), das Sie frei wählen können.
  • Eine zufällig generierte, anonyme User-ID, um Ihre eigenen Einträge zuzuordnen (damit Sie diese später wieder löschen können).
  • Die technischen Parameter des Synthesizers (z. B. gewählte Tonleiter, Wellenform, Regler-Werte für Gipfel, Täler, Echo etc.).
  • Einen Zeitstempel der Speicherung.

Diese Daten erlauben keinen Rückschluss auf Ihre reale Person. Bitte verwenden Sie als Pseudonym keine echten Vor- und Nachnamen, wenn Sie anonym bleiben möchten.

3. Lokaler Speicher (Local Storage)

Um Ihren gewählten Spitznamen und Ihre anonyme User-ID für zukünftige Besuche auf Ihrem Endgerät zwischenzuspeichern, nutzt diese Website die „Local Storage“-Funktion Ihres Browsers. Wir setzen keine Tracking-Cookies oder Analyse-Tools ein, um Ihr Surfverhalten zu überwachen.

4. Externe Dienste (Hosting & Datenbank)

Diese Website greift auf zwei externe Dienste zurück, um technisch funktionieren zu können:

  • GitHub Pages: Die Website wird über GitHub gehostet. Beim Aufruf der Seite überträgt Ihr Browser aus technischen Gründen standardmäßig Ihre IP-Adresse an die Server von GitHub.
  • Google Web Apps (Google Sheets): Die geteilten Presets der Community werden in einer Google Tabelle gespeichert. Beim Speichern oder Laden von Presets kommuniziert Ihr Browser direkt mit den Google-Servern.

5. Ihre Rechte & Löschung

Sie können Ihre eigenen, mit Ihrem Pseudonym gespeicherten Presets jederzeit über das Interface der Website selbst wieder löschen. Wenn Sie Ihren lokalen Speicher (Local Storage) in den Browser-Einstellungen leeren, wird auch Ihre anonyme User-ID gelöscht. Danach können zuvor erstellte Presets nicht mehr durch Sie selbst aus der Datenbank entfernt werden.
